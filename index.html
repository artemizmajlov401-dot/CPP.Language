Почему C++ кажется сложным, хотя это не так

Why C++ seems hard, though it isn't

Многие думают, что C++ — это что-то запредельно сложное. Мол, там «указатели», «память», «шаблоны» — и всё это только для гениев. На самом деле это миф. C++ — это такой же язык, как Python, JavaScript или Java. Просто он честнее: он не прячет от тебя то, что происходит внутри.

Many people think C++ is insanely hard. Like it has "pointers", "memory", "templates" — and all of that is only for geniuses. In fact, that's a myth. C++ is just a language, like Python, JavaScript or Java. It's just more honest: it doesn't hide what happens inside.

Сложность — не в языке. Сложность — в задачах, которые ты на нём решаешь. Сам язык простой. Ты просто учишься думать. А думать — это навык, который тренируется.

The difficulty is not in the language. The difficulty is in the tasks you solve with it. The language itself is simple. You just learn to think. And thinking is a skill you can train.

Lesson 1. What a program is and why C++ matters

Этот урок — для полных чайников. Если ты никогда не программировал и не знаешь, что такое «код», «компилятор», «файл» — читай внимательно. Здесь объясняется буквально каждое слово.

This lesson is for complete beginners. If you've never programmed and don't know what "code", "compiler" or "file" mean — read carefully. Every single word is explained here.

Что такое компьютер и что такое программа

What a computer is and what a program is

Компьютер — это машина, которая умеет выполнять команды. Сама по себе она ничего не делает: ей нужно сказать, что делать. Эти указания называются программой.

A computer is a machine that can execute commands. By itself it does nothing: it needs to be told what to do. These instructions are called a program.

Программа — это список команд, записанных в файле. Ты пишешь команды на понятном тебе языке, а компьютер их выполняет.

A program is a list of commands written in a file. You write commands in a language you understand, and the computer executes them.

Что такое язык программирования

What a programming language is

Компьютер не понимает русский или английский. Ему нужно объяснять на специальном языке — языке программирования. Языков много: Python, JavaScript, Java, C++, и другие.

The computer doesn't understand Russian or English. It needs to be told in a special language — a programming language. There are many: Python, JavaScript, Java, C++, and others.

C++ — один из них. Он считается мощным, потому что даёт программисту контроль над всем, что происходит внутри. Но учить его — не сложнее, чем любой другой язык.

C++ is one of them. It's considered powerful because it gives the programmer control over everything inside. But learning it is no harder than any other language.

Что такое компилятор и зачем он нужен

What a compiler is and why we need it

Компьютер понимает только машинный код — это нули и единицы, вроде 10110100. Писать такое вручную невозможно. Поэтому мы пишем на C++ — а специальная программа-переводчик превращает наш текст в машинный код.

A computer understands only machine code — zeros and ones, like 10110100. Writing that by hand is impossible. So we write in C++, and a special translator program turns our text into machine code.

Эта программа-переводчик называется компилятор. Она берёт наш файл с кодом и делает из него файл, который компьютер может запустить.

This translator is called a compiler. It takes our code file and produces a file the computer can run.

Разбор каждого страшного слова

Every scary word explained

#include — «включить». Команда, которая говорит компилятору «подключи сюда готовые инструменты».

#include — "include". A command that tells the compiler "plug ready-made tools in here".

iostream — «ай-о-стрим», от input-output-stream — «поток ввода-вывода». Инструменты для чтения с клавиатуры и вывода на экран.

iostream — "input-output-stream". Tools for reading from the keyboard and printing to the screen.

int — от «integer», целое число. Тип данных.

int — from "integer". A data type.

main — «главная». Имя функции, с которой начинается любая программа.

main — "main". The name of the function every program starts with.

() — скобки. Внутри них обычно параметры. У main их нет, поэтому пусто.

() — parentheses. Usually parameters go inside. main has none, so they're empty.

{ } — фигурные скобки. Открывают и закрывают тело функции.

{ } — curly braces. Open and close the function body.

std:: — «стандарт». Как папка с готовыми инструментами. std::cout — «возьми cout из стандартной папки».

std:: — "standard". Like a folder with ready tools. std::cout — "take cout from the standard folder".

cout — «си-аут», от character output — «вывод символов».

cout — "character output".

<< — две стрелки влево. «Толкают» данные в поток вывода.

<< — two left arrows. They "push" data into the output stream.

cin — «си-ин», от character input — «ввод символов».

cin — "character input".

>> — две стрелки вправо. «Вытягивают» данные из cin в переменную.

>> — two right arrows. They "pull" data from cin into the variable.

std::endl — «энд-лайн», конец строки. Переносит курсор на новую строку.

std::endl — "end line". Moves the cursor to a new line.

string — «строка». Набор символов. Тип данных для текста.

string — "string". A sequence of characters. Data type for text.

; — точка с запятой. В C++ каждая команда заканчивается ею.

; — semicolon. In C++ every command ends with it.

Как выглядит первая программа

What the first program looks like

#include <iostream>

int main() {
    std::cout << "Hello, world!" << std::endl;
    return 0;
}

Это стандартный каркас. Первая строка — подключает iostream. Вторая — открывает главную функцию main. Внутри — команда вывода. В конце — возврат нуля.

This is the standard skeleton. The first line includes iostream. The second opens main. Inside — a print command. At the end — return zero.

Как скомпилировать и запустить

How to compile and run

g++ main.cpp -o main
./main

Первая команда — компилирует. Вторая — запускает. В Windows вторая команда: main.exe.

The first command compiles. The second runs. On Windows the second is main.exe.

Урок 2. Переменные и типы данных

    
Lesson 2. Variables and data types


    
Этот урок — для полных чайников. Разберём, что такое переменная, зачем нужны типы, какие типы есть в C++, как объявить переменную, как её напечатать и как что-то в неё записать с клавиатуры.

    
This lesson is for complete beginners. We'll cover what a variable is, why types exist, which types C++ has, how to declare a variable, how to print it, and how to read something into it from the keyboard.


    
Что такое переменная

    
What a variable is


    
Переменная — это ячейка в памяти компьютера, у которой есть имя. В неё можно положить значение: число, букву, текст. Потом это значение можно менять. Представь коробку с наклейкой: на наклейке — имя (например, age), внутри — значение (например, 15).

    
A variable is a memory cell with a name. You can put a value in it: a number, a letter, a text. Later you can change that value. Imagine a box with a label: the label is the name (for example, age), inside is the value (for example, 15).


    
Зачем нужны типы данных

    
Why data types are needed


    
У каждой переменной есть тип. Тип говорит компьютеру, что за данные лежат внутри: целое число, дробное, буква, текст. От этого зависит, сколько памяти выделить и как обрабатывать значение.

    
Every variable has a type. The type tells the computer what kind of data is inside: whole number, decimal, letter, text. This affects how much memory to allocate and how to process it.


    
Например, целое число 5 хранится иначе, чем дробное 5.5, а буква 'A' — иначе, чем строка "Alex". Поэтому в C++ у каждой переменной должен быть указан тип.

    
For example, the whole number 5 is stored differently from the decimal 5.5, and the letter 'A' differently from the string "Alex". That's why in C++ every variable must have a type.

Main C++ types


    
    
        
  • int — целое число. Пример: 5, -10, 100, 0.
    • 
        
  • int — whole number. Example: 5, -10, 100, 0.
    • 
        
  • double — дробное число. Пример: 3.14, -0.5, 2.0.
    • 
        
  • double — decimal number. Example: 3.14, -0.5, 2.0.
    • 
        
  • char — один символ в одинарных кавычках. Пример: 'A', 'z', '5'.
    • 
        
  • char — one character in single quotes. Example: 'A', 'z', '5'.
    • 
        
  • bool — правда или ложь. Значения: true, false.
    • 
        
  • bool — true or false.
    • 
        
  • std::string — строка текста в двойных кавычках. Пример: "Привет".
    • 
        
  • std::string — text string in double quotes. Example: "Hello".

A character uses single quotes ('A'), a string uses double quotes ("Alex"). Different things.

First the type, then the name, then =, then the value. Each line ends with a semicolon.

Variable name rules

  • Case matters: age and Age are different

How to print a variable

You can print text and variables together with <<. The compiler inserts the value in the right place.
